# Teste de arquitetura

Protótipo local e isolado: não participa da navegação do site publicado.

Abra `index.html` diretamente no navegador ou, a partir da pasta `site`, execute:

```sh
python3 -m http.server 8787
```

Depois abra `http://localhost:8787/testes-arquitetura/`.

Esta é uma cópia fiel da estrutura visual e funcional do Guia Vila Mascote: arquivos separados de dados, interface, estilos e comportamento; as mesmas imagens remotas das categorias; busca, categorias, subcategorias, ordenação, cards e mapa sincronizados com lista lateral e camadas Mapa/Satélite. A marca, o logo, a paleta, as coordenadas e os 56 estabelecimentos vêm do projeto Campo Belo.

Nada neste diretório deve ser publicado ou integrado ao site sem aprovação explícita.
